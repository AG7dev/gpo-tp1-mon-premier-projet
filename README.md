# R2.10 - Gestion de Projets et Organisation
 
## TP1 - Tableaux Kanban, GitHub & GitHub Projects
 
Ce dépôt GitHub a pour but de nous familiariser avec les bases de GitHub et la gestion de projet à l'aide d'un tableau Kanban. À travers cette introduction, nous découvrons comment organiser des tâches, suivre leur avancement et utiliser les principales fonctionnalités de GitHub dans un contexte de travail collaboratif.
